# Static Website Page

## Project Description

This project demonstrates the creation of a responsive static website using HTML, CSS, and JavaScript. The website is designed with a mobile-first approach, utilizing modern web technologies to ensure a seamless user experience across desktops, tablets, and mobile devices.

## Features
- **Responsive Design**: The layout automatically adjusts to various screen sizes using media queries. The website is fully optimized for mobile, tablet, and desktop views.
- **HTML5 Semantic Markup**: The structure of the website uses HTML5 semantic elements for improved accessibility and SEO.
- **Custom CSS Styling**: The website’s design is tailored to the given design using custom styles, ensuring proper layout, typography, and color schemes.

## Setup Instructions
To view the project locally, follow these steps:


###  1. Clone the repository
```bash
git clone https://github.com/YourUsername/Static-Website.git

```
### 2. Navigate to the project directory:
```bash
cd Static-Website
```
### 3.Open the ```index.html``` file in your preferred browser 
You can open the index.html file directly in your browser, as no server setup is required for this static website.

### 4. View the website
 The website will load and display with a responsive design, adapting automatically to different screen sizes.

## Challenges Faced
- **Responsive Design:** One of the key challenges was ensuring that the layout works seamlessly across a variety of screen sizes. Using Flexbox and CSS Grid helped create a responsive layout that adjusts easily to mobile, tablet, and desktop devices.

## Tools Used
- **HTML5:** Used for creating the structure and content of the website.
- **CSS3:** Custom styles were used to define the layout, colors, typography, and responsiveness.
- **JavaScript:** JavaScript was used for dynamic interactivity, such as handling modals, hover effects, and responsive features.
- **Responsive Design:** Media Queries were used to ensure proper responsiveness.
